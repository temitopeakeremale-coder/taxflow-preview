# TaxFlow preview

Live preview of TaxFlow, a workspace for Nigerian tax practitioners.

**Open the app:** https://temitopeakeremale-coder.github.io/taxflow-preview/
**With example clients:** https://temitopeakeremale-coder.github.io/taxflow-preview/#demo

This repository holds only the built website and is updated automatically. Data you enter stays in your own browser on your own device; nothing is sent to a server. Figures are estimates for practitioner review, not tax advice.
